# Model furnitur

Semua model 3D dan gambar kecil di folder ini berasal dari [Poly Haven](https://polyhaven.com)
dan berlisensi [CC0](https://creativecommons.org/publicdomain/zero/1.0/): bebas dipakai,
diubah, dan dibagikan tanpa wajib mencantumkan sumber. Sumbernya tetap dicatat di sini.

Model diubah ke `.glb` dengan tekstur WebP maksimal 1024 px; beberapa model daun dan lemari
disederhanakan agar ringan di browser.
